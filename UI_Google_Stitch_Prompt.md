# Google Stitch UI Prompt for UNI-ATTENDENSE-WITH-IoT

## Project UI Prompt

Create a modern, minimalistic, and simple web application UI for the UNI-ATTENDENSE-WITH-IoT project. Use the attached reference image as the theme basis: clean white and light gray background, subtle shadows, soft color accents, and a neat card layout. The UI should feel polished, lightweight, and easy to scan.

### Global Style
- Minimalist color palette: white, light gray, charcoal, soft blue or teal accents.
- Use plenty of white space and subtle card surfaces.
- Simple sans-serif typography with clear hierarchy.
- Rounded corners for cards, buttons, and containers.
- A modern left-side navigation layout with icons and text.
- A top bar with a page title, search field or action button, and user/account area.
- Consistent spacing, clean lines, and minimal decorative elements.

### Pages and Components

#### 1. Login Page
- A centered login card on a light background.
- Fields for "Email" and "Password".
- A primary action button labeled "Sign In".
- A small link or text for "Forgot password?".
- Minimal header text such as "Welcome Back" and a short subtitle.

#### 2. Admin Dashboard
- A dashboard screen with a left navigation panel.
- Navigation items include: Dashboard, Attendance, Students, Faculty, Reports, Settings.
- The top header should show a page title, a compact search input, and a profile/avatar area.
- The main content area should use information cards and a clean data section.
- Include sections for: quick attendance stats, active devices, and recent activity.
- Use card groups with subtle borders and accent buttons like "View Complete History".

#### 3. Faculty Dashboard
- Similar layout to Admin Dashboard but tailored for faculty tasks.
- Left navigation can include: Dashboard, Class Attendance, Students, Schedule, Notifications.
- Main area should show attendance summary cards, class list cards, and action buttons.
- Provide a focused panel for current class, student status, and quick scan controls.

#### 4. Student Dashboard
- A simplified dashboard experience for students.
- Include a header with the student name or role and a small profile badge.
- Main cards for current attendance status, next class, and attendance history.
- A minimal list or tile view for enrolled classes or recent sessions.

#### 5. Shared Components
- Left navigation menu: icons, labels, active state highlight, compact and modern.
- Top bar: search field, notification icon, profile avatar, and quick action button.
- Cards: use soft shadows, rounded corners, and light backgrounds.
- Buttons: primary accent button for main actions, secondary muted buttons for less important actions.
- Table or list rows: clean divider lines and minimal row actions like "Confirm", "Reject", "Details".

### Behavior and Tone
- Keep the UI calm and professional.
- Avoid heavy visuals, gradients, or overly bold contrasts.
- Prioritize usability and clarity over decorative styling.
- The interface should feel like a modern dashboard product with a tech/attendance focus.

### Output Format
- Generate the UI as a set of Stitch screens with pages and reusable components.
- Include the Login screen plus the Admin, Faculty, and Student dashboards.
- Use the reference image theme to guide spacing, card layout, and palette.
- Keep the design consistent across all pages.
